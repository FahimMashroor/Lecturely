# Lecturely

Live lecture transcripts in 90+ languages, with study tools that turn a lecture
into notes, summaries, quizzes and lessons.

By Fahim Mashroor.

## What it does

- Records a lecture and writes it out live, about every 30 seconds.
- Works online, and also without internet after a one-time download.
- Has a high-accuracy English pack for English lectures.
- Saves lectures on your device and exports them as Word, text or PDF.
- Runs as a website and as an Android app.

## Run the website on your computer

You need [Node.js](https://nodejs.org) or [Bun](https://bun.sh).

```sh
npm install
npm run dev
```

## Build the Android app

See [android/README.md](android/README.md).

```sh
bash android/build-apk.sh
```

## Tests

```sh
npm test
```

## Built with

TypeScript, React, TanStack Start and Tailwind CSS.
